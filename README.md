## ¿Qué es colorized-log?

Una manera sexy y elegante de realizar logs decorados.

## Modo de uso

```javascript
import Console from 'colorized-log';

Console.log([{ text: 'Hello World', color: 'red', format: 'bold' }]);

// Puedes agregar más de un estilo en la misma línea
Console.log([
    { text: 'Hello', color: 'red', format: 'bold' },
    { text: 'World', color: 'green', background: 'yellow' },
]);
```
