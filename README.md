## ¿Qué es astro-amp?

Es una extensión para Astro que permite tomar el contenido de los archivos .css, generados automáticamente por Astro, y los inyecta directamente en el documento HTML final.

Lo que se busca es que los estilos se carguen correctamente en las páginas AMP de tu proyecto de manera consistente, sin necesidad de hacerlo manualmente a lo largo del proyecto.

Funciona tanto para estilos definidos por el usuario como con los estilos integrados de Tailwind.
